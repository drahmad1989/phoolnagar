🌸 PHOOLNAGAR.COM WEBSITE — CLOUDFLARE HOSTING GUIDE 🌸
========================================================

STEP 1: Cloudflare Pages par website upload karein
--------------------------------------------------
(Tareeqa 1 — Sab se asaan: Drag & Drop)
1. https://dash.cloudflare.com par jayen aur account banayen/login karein
2. Left menu me "Workers & Pages" par click karein
3. "Create application" → "Pages" → "Upload assets" par click karein
4. Project ka naam likhein: phoolnagar (ya phoolnagar-com)
5. index.html file ko drag karke upload karein
6. "Deploy site" dabayen — 30 second me website LIVE! 🎉

STEP 2: pholnagar.com domain connect karein
--------------------------------------------------
1. Cloudflare Pages me apne project ko kholein
2. "Custom domains" tab → "Set up a custom domain"
3. Likhein: pholnagar.com → Continue
4. Agar domain pehle se Cloudflare par hai → ye khud hi connect ho jayega
5. Agar domain kahin aur hai (GoDaddy waghera):
   - Pehle domain ko Cloudflare me add karein (Add site)
   - Nameservers change karne honge (Cloudflare 2 nameservers deta hai)
   - Papa ki madad se ye step karein

STEP 3: APNA PHONE NUMBER DALO (ZAROORI!)
--------------------------------------------------
1. index.html file ko Notepad / VS Code me kholein
2. Ye line dhoondein (file ke shuru ke paas hai):
   var DERA_PHONE = '923001234567';
3. 923001234567 ki jagah APNA number likhein
   (92 se shuru, + ke baghair — misal: 923004567890)
4. File save karein aur dobara upload kar dein

Ye number Dera Talk chat ke "Call Karein" aur "SMS se Bhejein"
buttons me use hota hai. Jab customer SMS bhejta hai to poora
message (naam, number, order) aap ke phone par aa jata hai!
